## 🔄 與「英雄升星基金」聯動策略

| 決策點 | 建議 |
|--------|------|
| **基金是否購買？** | 若目標英雄在基金獎池內，**強烈建議買**（性價比通常 > 直接轉盤） |
| **基金等級衝多少？** | 衝到「目標英雄滿星」所需等級即可，多餘不追 |
| **轉盤 vs 基金** | 先算基金性價比（總價/得碎片數），再決定轉盤抽幾次 |
| **碎片通用性** | 基金給的碎片通常**限定英雄**，轉盤給**通用/自選**，互補 |
