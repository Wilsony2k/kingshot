# Kingshot 伺服器成長時間線指南

> 來源：遊戲社群整理，Wilson 提供  
> 用途：依伺服器齡（開服天數）推算功能開放、英雄/寵物世代、SvS 時機，配合活動規劃資源分配

---

## 核心原則
- **基準日** = 伺服器建立日（非合服日）
- **確認技巧**：
  - VIP 進度無漏簽 → 依 VIP 紀錄推算
  - 有漏簽 → 里程碑最上方目標達成日 − 7 天
- **誤差範圍**：±10~20 天（視伺服器進度調整）
- **持續更新中**，最終預計覆蓋至 TG10 區間

## 與活動評分表的串聯邏輯

1. **英雄轉盤（90k/8k 分）** → **每期最強領主 Day 2** 必留次數  
   - 依時間線：第 3 世代(100~120日)、第 4 世代(190~200日)、第 5 世代(260~280日)釋出前後的最強領主期，**轉盤獎池會更新新世代英雄**，這幾期 **Must Do 120 抽**
2. **高級馴化印記（150k/15k 分）** → **最強領主第三期 Day 4** 獨佔 150k  
   - 若伺服器齡 ≈ 100~200 日（第 3/4 世代寵物剛出），印記產出稀缺，**絕對禁用於 KVK**
3. **英雄專屬裝備組件（100k 分）** → 每期實力衝刺日  
   - 新世代英雄釋出後 1~2 個最強領主期，組件會對應新英雄，**優先留給新主力**
4. **秘銀（40k 分，KVK 獨有）** → KVK 英雄成長/實力衝刺階段  
   - 最強領主無此項，KVK 期間**專用於 KVK**
5. **加速道具** → **最強領主第三期 Day 7（300 分/分）** 最高 ROI  
   - 其次：最強領主 Day 1~6 研究/建造（隱含 45/30 分/實力）→ 換算分/分鐘
   - KVK 只有 30 分/分，**加速留給最強領主第三期 Day 7**
6. **士兵訓練** → **最強領主 Day 3（90~1960 分/隻）** 遠超 KVK（3~60 分）  
   - 訓練高階兵（9/10 級）留最強領主 Day 3，**卡點 00:00 後完成**
7. **領主裝備評分** → 最強領主第二/三期 Day 6（500 分/點）vs KVK（70/36 分）  
   - **突破/洗鍊留最強領主 Day 6**

## 實用工具：伺服器齡快速推算器

```python
# 粗略 Python 片段，實際可做成網頁小工具
def server_age_days(vip_days_logged, milestone_top_days=None):
    if vip_days_logged is not None:
        return vip_days_logged  # 無漏簽情況
    if milestone_top_days is not None:
        return milestone_top_days - 7
    raise ValueError("需提供 VIP 連簽天數 或 里程碑頂端達成日")

def upcoming_milestones(age):
    milestones = [
        (0, "1st Gen Heroes"),
        (14, "Plains Fog Clear"),
        (38, "2nd Gen Heroes"),
        (40, "Alliance Resource Exchange"),
        (45, "Castle Battle"),
        (54, "1st Gen Pets"),

        (100, "3rd Gen Pets"),
        (100, "3rd Gen Heroes"),

        (190, "4th Gen Pets + Heroes"),
        (220, "War Academy"),
```
